# SEC-HPLC Virtual Lab

범용 SEC-HPLC 장비 운용을 배우는 **교육용 Streamlit 앱**입니다. 실제 장비에 연결하거나 제어하지 않습니다.

## 실행

Windows에서 Python 설치 후 `run_windows.bat`를 더블클릭하거나 터미널에서:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저가 자동 실행되지 않으면 터미널에 표시된 `http://localhost:8501`을 엽니다.

## 실습 순서

1. 장비 구조에서 유로 및 SEC 원리 학습
   - 실제 HPLC 장비, 컬럼, 연결부 참조 사진을 보고 구성요소를 식별합니다.
   - 필요하면 해당 실험실 장비 사진을 업로드하여 현장 장비 기준으로 설명합니다. 업로드 사진은 브라우저 세션에만 표시됩니다.
2. 장비 운용: 이동상 확인 → 전원 ON → Purge → 컬럼 연결 확인 → Pump ON/평형화
3. Blank → Standard → Sample 순서로 분석
4. 크로마토그램과 피크 면적비 확인, CSV 다운로드
5. 오류 대응 훈련 및 평가·보고서 다운로드
6. 세척·종료 (실제 세척 방법이 아닌 상태 전환 시뮬레이션)

## 교육 모델 한계

- 압력은 실제 컬럼/장비 모델과 무관한 임의 계산입니다.
- 피크는 Gaussian 가상 데이터로, 실제 분석법 검증이나 정량에 사용할 수 없습니다.
- 주입량, pH, 염 농도, 온도는 설정 교육용이며 모든 항목이 피크 모델에 정량적으로 연동되지는 않습니다.
- 피크 면적비는 UV 응답 기준의 모의 비율이며 질량 순도가 아닙니다.
- 장비 제조사 매뉴얼과 실험실 SOP를 대체하지 않습니다.
- 실제 SEC 분석은 컬럼의 분획 범위, 유속·압력 한계, 이동상 및 시료 안정성을 확인해야 합니다.
- 장비 구조 화면의 참조 사진은 Wikimedia Commons의 실제 장비 사진이며, 사진별 원본·라이선스 링크를 앱에 표시합니다. 현장 사진과 제조사 SOP가 우선입니다.
